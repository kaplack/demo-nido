# demo-nido

Demos de páginas web para nidos y centros de educación inicial.

## Stack

- Vite
- React
- React Router
- CSS

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Rutas

- `/` — selector de demos
- `/demos/colores-y-sonrisas` — primera demo

Pensado para desplegarse en Vercel y conectarse a:

`demo-nido.alanburga.com`
